# **Teachers Dashboard**

Web application designed for managing questions, metadata, and operations like filtering, pagination, and caching. It is containerized using Docker for easy deployment.

---

## **Features**
- **Frontend**: React.js with Bootstrap for UI and dynamic operations.
- **Backend**: Flask for RESTful APIs and SQLAlchemy for database management.
- **Caching**: Flask-Caching for improved performance.
- **Dockerized**: Simplified deployment using Docker.

---
